# Agent notes for byw1/byw1

This is William Lee's GitHub **profile README** repo. `README.md` *is* the profile page, so it must contain only what should appear on github.com/byw1. ## Map

- `README.md` is the page itself. Its order: signature banner, `### projects` (4 cards), tech stack badges, the stats card, the "contributions in the last year" line, the snake, and the favorite-reads shelf. William removed the README's link to the docs himself, so don't add it back.
- `assets/*.svg` are generated by `scripts/build-assets.py`. **Never hand-edit them**: change the script, then run `python3 scripts/build-assets.py` (needs `pip install fonttools brotli pillow`) and commit the script and the SVGs together.
- `scripts/stats.py` draws `stats.svg` (streaks and top languages). It runs only inside the Action, because it needs `GH_TOKEN`.
- `.github/workflows/snake.yml` runs every 12 hours, on every push, and on manual dispatch. It writes `snake*.svg`, `contributions*.svg` and `stats.svg`, then force-pushes them to the `output` branch. Never commit to `output` by hand.
- `scripts/icons/` holds the 256×256 app icons for the project cards. `scripts/signature.json` holds the signature's two SVG paths, which come from bywilliaml.com's `src/components/ui/signature-intro.tsx`.

## How to check your work

- Render changed SVGs in a real browser (Playwright/Chromium is fine) as `<img>` tags, several on one page, and wait about 5 seconds so the animations finish. Blank text usually means a font-family name clash (see the gotchas in docs/SETUP.md).
- After pushing, confirm the Action run succeeded, then load https://github.com/byw1 and check that every `article img` loaded. `raw.githubusercontent.com` can serve a stale copy for about 5 minutes.
